Questions answered

Does code leave my infrastructure?

Not unless you enable LLM steps. Parsing, resolution, embeddings, search and the ledger run locally and write to the directory or bucket you choose. --no-llm turns every LLM step off.

Do I need to run a server?

No. A folder or your own bucket holds the index; CI builds it and every agent reads it. A team that wants sign-in, roles and a shared web app runs one container.

How fresh is the index?

As fresh as the last build. Re-indexing is incremental, readers switch versions atomically, and hooks on a remote index read a local mirror that refreshes in the background.

Which agents work with it?

Any agent that speaks MCP: Claude Code, Cursor, Codex, Gemini CLI and others. comindly serves MCP over stdio, or over HTTP from a team server.

Which languages?

Python, TypeScript, JavaScript, Go, Java, Kotlin and Rust.
